## Processing rules

1. Do not flatten these files into one monolithic prompt.
2. Preserve the original source terminology and historical conflicts.
3. Treat older pricing, included-minute claims, and legacy GHL Voice AI runtime assumptions as source history, not current authority.
4. Normalize into PROPOSED Project Knowledge records first.
5. Compare against FINAL/CURRENT Project Knowledge before promotion.
6. Never persist credentials, API keys, tokens, or other secrets from source material.
7. Keep raw source provenance distinct from normalized architecture.

## Known limitation

ChatGPT File Library items are referenced source objects rather than directly mounted binary files in this runtime. This Batch 1 package therefore contains curated, provenance-labeled source extracts and architecture notes rather than byte-for-byte copies of every original DOCX/XLSX/TXT. Original files should be archived to R2 later when a supported object-upload path is available.
